# Luma Circle

A membership circle for trans, nonbinary, and pan adults.

## Theme

Vibrant LGBTQ+ pride redesign: deep night backgrounds, hot pink accents, animated rainbow gradients on primary actions, pride flag bars, and colorful borders.

Originally a quiet rose-mist aesthetic — now loud, proud, and unapologetically queer.

## Features

- Discover / For you / Following feeds
- Creator profiles, posts (free / subscriber / unlock)
- Messaging, tips, subscriptions
- Ledger, reports, verification
- 18+ only

Built with TanStack Start, Tailwind v4, Better Auth.

## Development

```bash
npm install
npm run dev
```

Preview on port 8080.
